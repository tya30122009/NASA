# Demo Walkthrough Script: 3I/ATLAS

1. **The Problem:** SPHEREx maps the sky in 102 near-infrared bands, but raw FITS files are locked behind archive queries and complex LVF calibration.
2. **The Solution:** Open QuickX, search for "3I/ATLAS" or pick any sky coordinates.
3. **The Science:** QuickX matches frames by exact per-pixel LVF wavelength, ensuring that color shifts are never mistaken for physical motion.
4. **The Action:** Use Blink mode to watch the interstellar visitor move across epochs against fixed stars.
